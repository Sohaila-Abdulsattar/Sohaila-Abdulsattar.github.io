Research
Interests

01

Code generation

Improving how language models generate code and understanding where they fail, with the goal of making the code they produce more reliable

02

Agentic coding

Evaluating how LLM-based agents handle larger, multi-step software engineering tasks, and what limits them in real projects

03

Interpretability

Interpreting the internal representations of language models to understand what they encode about code and how that relates to their behavior

04

Reinforcement learning

Using reinforcement learning to strengthen the reasoning abilities of language models, and studying how reward signals shape the code they produce
